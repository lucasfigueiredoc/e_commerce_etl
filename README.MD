## Data Lakehouse Local: E-Commerce Analytics (Olist)

# Visão Geral do Projeto

Este projeto simula uma arquitetura corporativa completa de Big Data & Analytics para uma empresa de E-commerce (baseado no dataset público da Olist). O objetivo principal é construir um Data Lakehouse, aplicando a arquitetura Medallion (Bronze, Silver, Gold).

Toda a arquitetura foi desenhada para correr localmente via Docker, utilizando tecnologias Open-Source que simulam o comportamento de provedores de Cloud (como AWS e Azure).
